Tenant Playbook

Elevator not working right? You may have rights.

Who this is for: Rent-stabilized and rent-controlled tenants at 205 East 17th Street.
Emergency? If someone is trapped, an elevator shaft is open, or the elevator is moving dangerously — call 911, not 311.

The elevator can run and still be defective

If it bounces, stops unevenly, stalls, or otherwise operates unsafely or unreliably, document and report it. If proper service is not restored, you may be entitled to a rent reduction.

Three steps
1 File a 311 Complaint Report any actual malfunction — not only a complete outage › 2 Notify the Landlord Send a certified letter — sample letter included › 3 File with DHCR — Form RA-84 The official application for a rent reduction ›
Real-world result
A tenant at this building filed — and won. The reduction remains in effect after DHCR denied the owner's latest request to restore the rent.
