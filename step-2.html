Notify the Landlord by Certified Mail

Before filing with DHCR, send the owner a certified letter and keep proof of mailing. Certified Mail is recommended because it provides proof of notice and can avoid additional DHCR response time for the owner.

How to send

Ask USPS for Certified Mail. A Return Receipt is optional but helpful.

Mail to:
205 Realty Holdings LLC
1274 49th Street, Suite 175
Brooklyn, NY 11219
Use this sample letter
[Your Name] 205 East 17th Street, Apt. [Your Unit] Brooklyn, NY 11226 [Date] 205 Realty Holdings LLC 1274 49th Street, Suite 175 Brooklyn, NY 11219 Dear 205 Realty Holdings LLC, On [date and time], the elevator at 205 East 17th Street [describe exactly what happened: bounced hard / stopped below floor level / doors failed to reopen / stalled between floors]. Although the elevator may still be operating, this condition prevents safe, reliable elevator service. Please investigate, properly correct the condition, and confirm the work in writing. If the problem is not resolved, I will apply to DHCR for a rent reduction. Sincerely, [Your Name] [Your Phone / Email]
Before mailing
  • Fill in your name, unit, date, and description of the problem
  • Sign the letter and make a copy
  • Send via Certified Mail — keep the receipt
  • Keep the return card if it arrives
